# Configurations

Each setting has scientific settings separate from inputs and outputs. RQ1 records reported conditions, estimator grids and evaluation rules. RQ2 records method roles, exact index construction settings and query-generation parameters; model identities and prompt text live in their own directories. RQ3 records methods, complete condition grids and separate ecosystem support. RQ4 records fixed utility definitions, six-rule implementation settings, stochastic seeds and budgets.

Scientific identity strings and seed namespaces may retain version tokens because changing them would change the benchmark. Paths and filenames do not encode development iterations. Operational run status, schedulers and private handoff records are not configurations for this release.
