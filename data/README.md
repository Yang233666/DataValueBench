# Benchmark inputs

Inputs are organized by evaluation setting; frozen scientific outputs are under `results/`. See [DATA.md](../docs/DATA.md) for schemas, identity joins, release categories and external prerequisites. `external_inputs.json` records exact missing snapshot identities and affected reconstruction stages. Bundled files require no API calls to inspect.
