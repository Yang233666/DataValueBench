# RQ2 · Metadata-based dataset retrieval

The benchmark fixes 100,000 Hugging Face metadata records and 500 latent intent slots: 300 single-condition and 200 two-condition slots. The fields are tags, task categories, task contexts, language and license. Normalization lowercases, strips enclosing punctuation, splits the specified delimiters, trims whitespace, drops empty/null-like tokens and deduplicates field tokens. No ontology, synonym expansion, translation or result-dependent selection is introduced. Eligible positive sets contain 20–20,000 datasets. Two-condition predicates use distinct fields and conjunction.

All 500 latent intents, Track A structured queries and automatic qrels are released. Exactly 475 unique Track B queries are realized: 275 single-condition and 200 two-condition. The other 25 slots have explicit construction-exhaustion reasons in `unrealized_track_b_slots.jsonl`. This is query-realization N/A, not RQ3's mathematical structural inapplicability. All 12 reported methods use the same 475-intent support. N/A slots are never zero-valued evaluation rows. Field coverage is preserved in `results/rq2/query_realization_coverage.json`.

Track A's ExactMetadataFilter is a structured reference aligned with the automatic metadata-derived relevance definition. Track B includes query-independent controls, TF-IDF, BM25, SPLADE, Multilingual E5, BGE-M3, GTE, ColBERTv2 and BM25/BGE reciprocal-rank fusion. Exact complete-corpus ranking and deterministic ID tie ordering are preserved. Model/index settings are under `configs/rq2/`; approximate retrieval is not an allowed replacement.

Qwen generated query candidates using only the latent conditions. `prompts/rq2/` and `rq2_query_generation.py` retain the prompt and deterministic seed rule. Semantic validation checks query fidelity to the intent, not relevance of retrieved datasets. The final workload contains 27 pilot human-verified and 448 Astra-validated queries; it is not described as fully human verified. Personal annotation identities and raw conversations are excluded. Human relevance and secondary reranking are outside the reported analysis.

`bash scripts/reproduce_rq2.sh` checks the 500/475/25 partition, query uniqueness, Track A identities, qrel support counts and all 5,700 method/intent rows, then recomputes nDCG@10 and MAP macro means. Saved pairwise effects, Holm results, bootstrap intervals and stratified/workload summaries remain in `results/rq2/`; verification does not rerun stochastic statistics. Full retrieval re-execution needs the exact external metadata snapshot and model/index inputs. Final queries avoid any need to rerun Qwen or remote Astra validation.
